---
title: "Massive Resource Updater"
description: "Plugin to update resources in ArchiHUB"
---

The plugin allows you to update resources in ArchiHUB. This plugin is included by default in the application and does not need to be installed, although, like other bundled plugins, it must be activated from the **Plugins** submenu of **System Administration** before it appears in the processing menu. The plugin allows you to create or update as many resources as you want in a single run, from an Excel file in the same format as the one generated by the [inventory generator](/archihub.github.io/en/inventory_maker) plugin. The following steps describe how to update resources:

## Update resources

1. **Access the plugin**: to access the resource update plugin, go to the processing tab in the ArchiHUB interface and select the `MASS PROCESSING` button from the resource update plugin.
2. **Prepare the Excel file**: generate an inventory with the [inventory generator](/archihub.github.io/en/inventory_maker) plugin, then edit it — editing existing rows updates those resources, and adding new rows creates new resources. Both edits and additions can be included in the same file.
3. **Select the file**: select the edited Excel file with the resources you want to create or update.
4. **Configure update**: the plugin allows you to delete resource fields when the Excel file has blank fields. Select the `Blank space as content deletion` option if you want blank fields to clear existing content instead of being left unchanged.
5. **Update resources**: once you have selected the Excel file, click on the `PROCESS` button. The plugin will create a processing task and the resources will be created or updated once the task has finished.

![Uploading and processing the Excel file](/archihub.github.io/imagenes/massiveUpdater.gif)

For the use of the plugin, it is important that there is at least one processing row available, as this depends on the tasks related to the processing of files being able to be executed. To create a processing row or validate that it exists, check the documentation on [processing rows](/archihub.github.io/en/nodos).

Once the processing is finished, the resources will be created or updated in ArchiHUB. You can verify the result from the cataloging module, or from **My profile** > **My processing** (in Spanish, "Tareas del sistema") if you want to review the processing report.
